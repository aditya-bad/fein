# AI Tools & Workflows for Stock Analysis, Picking and Trading (as of Nov 2026)

Research scope: what YouTube/blog workflows teach; Claude-specific skills/plugins/MCP servers; other tools (global + India); evidence on whether AI stock picking works; best practices. ~18 tool calls. YouTube transcript fetching was attempted (yt-dlp, youtubetotranscript.com) and blocked (bot-check / 403), so video content below comes from titles/descriptions and companion written guides, not transcripts.

## 1. Popular workflows (YouTube / blogs): actual steps and prompts

### Takeaway
The popular "use Claude/ChatGPT to analyze stocks" workflow is filing-first and adversarial: upload the primary documents (annual report, earnings deck, call transcripts), run a fixed library of saved prompts (business model, segments, moat, bull/bear/pre-mortem, forensic red flags, short-seller critique, management questions), and verify every number. Agentic variants (Claude Cowork/Code) add scheduled watchlist scans and Alpaca-connected paper-trading bots, but none of these come with a verified track record.

### Cited Findings
- YouTube videos found in 2026 include "How to Use Claude Sonnet to Analyze Stocks (2026 Step by Step Guide)" — [YouTube](https://www.youtube.com/watch?v=i3bwuJByiig); "How to Analyze Any Stock With Claude (FULL PROMPT)" (demo on Nike, reportedly Oct 2026 upload, uses the creator's own equity-research skill) — [YouTube](https://www.youtube.com/watch?v=e9QwRz7FvZE); "How to Use Claude AI to Analyze Stocks - Step by Step" — [YouTube](https://www.youtube.com/watch?v=YCASO2ZXiMA); "How To Actually Use Claude Code for Trading Strategies (Like a Quant)" — [YouTube](https://www.youtube.com/watch?v=EUSXhJNwRqI). Transcripts could not be retrieved (YouTube bot-check blocked yt-dlp; transcript site returned 403).
- **Michael Fritzell (Asian Century Stocks, 21 Apr 2026) workflow** — [Asian Century Stocks](https://www.asiancenturystocks.com/p/how-to-use-claude-for-equity-resear):
  - Set personal instructions ("I am ... an equity research analyst", brief answers, focus on business model/competitive position); use Sonnet for routine, Opus for complex multi-step analysis.
  - One Claude Project per prompt (prompt pasted as project instructions), then just type a ticker.
  - Prompt library: company overview ("Explain the company's business model in simple terms" + products, customers, suppliers, competitors, contract/payment terms); bull vs bear ("Act as an institutional-grade equity analyst" → bull case, bear case, pre-mortem, valuation, contrarian view ending in "what the market is currently refusing to see"); moat; supply-chain map; segment breakdown; earnings result vs consensus; earnings-call summaries tracking management sentiment over time; management assessment (tenure, insider ownership, capital allocation, ROE/ROIC); explain every >5% price move over five years; comps table (EV/Sales, EV/EBIT, P/E, yield, 5y avg ROE); forward EPS projection; forensic red flags ("You are a forensic equity analyst" — revenue recognition, segments, leases, related parties, contingencies, SBC, goodwill); 15 CEO questions ranked by information value; devil's advocate ("You are a skeptical short-seller" — test moat, concentration, capital allocation, valuation if growth disappoints 20–30%).
  - Uses Claude for Excel/PowerPoint add-ins on earnings decks; Cowork weekly scan of a 400-line Google Sheets watchlist for >10% 7-day moves, saved as a "skill" and scheduled via /schedule.
  - Caveats stated: AI makes mistakes, spreadsheet outputs need verification; quotas; prefers NotebookLM for large document sets.
- Filing-first approach: Claude quotes and reasons from the actual uploaded filing text; example prompt asks for segment revenue/EBITDA breakdown and flags guidance changes vs prior quarter — [Helm Terminal](https://helmterminal.dev/blog/claude-stock-analysis).
- Steelman prompt: ask Claude to construct the strongest possible bear case against your bull thesis using only public data — [Assistly](https://getassistly.co/blog/how-to-use-claude-for-stock-analysis).
- Prompt libraries exist for 10-K summaries, earnings-quality scoring, MD&A analysis — [Chartloom](https://www.chartloom.com/prompts).
- Anthropic's own Claude Academy tutorial recommends specifying tickers, metrics and time periods and keeping data requests manageable — [Claude Academy](https://academy.claude.com/tutorials/prompting-strategies-for-financial-analysis).
- "Turn Claude Code into your personal Wall Street analyst" guide (Claude Code + financial plugins) — [The Rundown](https://app.therundown.ai/guides/turn-claude-code-into-your-personal-wall-street-analyst).
- Claude Code trading bots: Alzarak/trading-bot is a Claude Code plugin for autonomous day trading with optional Alpaca MCP (44 tools), paper trading by default, and a daily-loss circuit breaker; repo shows features, not performance — [GitHub](https://github.com/Alzarak/trading-bot). BARCO-Alpaca hackathon agent uses Claude as decision layer via Alpaca MCP; self-reported $100,013 on $100,000 (single snapshot) — [lablab.ai](https://lablab.ai/ai-hackathons/alpaca-ai-trading-agents-hackathon/guacalita/barco-alpaca-ai-trading-agent). Blogger running three Claude/Alpaca paper bots reports Claude selling at a 3.2% loss after a trailing floor breach — [mejba.me](https://www.mejba.me/blog/claude-ai-automate-stock-trading). Hobby "MCP trader" author: "this bot was not built in order to make good financial decisions" — [vladg](https://vladg.bearblog.dev/mcp-trader/).

### Inferences
- The serious practitioner workflow is research augmentation (reading, summarizing, red-teaming), not "ask the AI which stock will go up." The bot/trading content is mostly build tutorials with paper-trading anecdotes.
- Saving prompts as Projects/skills and scheduling them (Cowork, Claude Code) is the 2026 evolution of the "prompt library" approach.

- Could not obtain YouTube transcripts (blocked); exact on-screen prompts of the top ChatGPT "pick stocks" videos are unverified. View counts not collected.
- Reddit (r/ValueInvesting, r/algotrading, r/IndianStreetBets) sentiment was not directly sampled.

## 3. Other tools and open-source projects (global + India)

### Takeaway
Open-source multi-agent frameworks (TradingAgents, virattt/ai-hedge-fund, FinRobot) dominate GitHub mindshare and are explicitly educational/research; Indian retail stacks combine Screener.in/Tijori/Trendlyne data with Claude/ChatGPT, increasingly via MCP connectors.

### Cited Findings
- **TradingAgents** (TauricResearch; arXiv 2412.20138, UCLA/MIT/Tauric): simulates a trading firm with fundamental, sentiment, news, technical analysts, bull/bear researcher debate, trader and risk team; paper reports improved cumulative return, Sharpe and drawdown vs baselines (short backtest window) — [arXiv](https://arxiv.org/html/2412.20138v4). Star counts reported ~80–85k (aggregator snapshots, conflicting) — [Pinggy](https://pinggy.io/blog/best_ai_trading_agents/); [SourcePulse](https://www.sourcepulse.org/projects/2368224).
- **virattt/ai-hedge-fund:** agents modeled on named legendary investors; describes itself as an educational proof-of-concept; ~59k stars per aggregator — [Pinggy](https://pinggy.io/blog/best_ai_trading_agents/).
- **FinRobot:** LLM agent platform for automated equity research report generation — [Pinggy](https://pinggy.io/blog/best_ai_trading_agents/).
- **India:** Screener.in has 10 years of financials and an AI filing-insight feature (free tier ~10 AI summaries/month per a comparison page); Tijori Concall Monitor gives transcript + AI summary shortly after calls (margins, guidance, capex); generic advice is to paste Screener data into ChatGPT/Claude because plain chatbots give stale/invented numbers for Indian companies — [Multibagg](https://www.multibagg.ai/market-pulse/articles/best-ai-powered-stock-research-platforms-in-india-2026-cmk3r8y1t0000rk7byp71mess); [Tijori AI stack, TradingQnA](https://tradingqna.com/t/tijori-s-ai-stack-for-company-research/194604); [LumiChats](https://lumichats.com/blog/ai-for-stock-market-investing-india-2026). A ValuePickr community Chrome extension turns Screener.in data into "institutional-grade" AI research prompts (incl. forensic analysis) — [ValuePickr](https://forum.valuepickr.com/t/tool-launch-free-chrome-extension-turn-screener-in-data-into-institutional-grade-ai-research-prompts-zero-data-collection-v2-0-0-us-stocks-forensic-analysis-under-review/218186). - **AI ETF:** AIEQ (IBM Watson-based) annualized ~+9.73% vs SPY +14.18% over ~9 years per one tracker; 0.80% expense ratio vs 0.09% for SPY; recent 1-year figures conflict across sources — [PortfoliosLab](https://portfolioslab.com/tools/stock-comparison/AIEQ/SPY); [ETF Central](https://www.etfcentral.com/compare-etfs/AIEQ-vs-SPY); [FA Mag](https://www.fa-mag.com/news/ai-powered-etf-getting-left-behind-by-an-ai-powered-stock-rally-73310.html?section=).

## 4. Evidence: does AI stock picking work?

### Takeaway
Evidence is weak-to-negative for autonomous LLM trading and mixed-but-unproven for LLM stock picking. Academic signals (news-sentiment → next-day returns) are real but small, aggregate-only, and partly inflated by memorization/look-ahead bias. Live contests (Alpha Arena) show most LLMs lose money, mainly through overtrading; popular "ChatGPT portfolio beat the market" headlines are short-window paper portfolios with non-comparable rules.

### Cited Findings
- **Lopez-Lira & Tang, "Can ChatGPT Forecast Stock Price Movements? Return Predictability and Large Language Models"** (v1 Apr 2023, latest v6 Oct 30 2025): ChatGPT headline sentiment scores significantly predict next-day returns, outperform traditional sentiment methods; earlier models (GPT-1/2, BERT) fail — [arXiv v6](https://arxiv.org/pdf/2304.07619v6); [arXiv v4](https://arxiv.org/pdf/2304.07619v4.pdf). Per-headline accuracy ~51%; signal only emerges in aggregate across many firms/days — [Fortune](https://fortune.com/2023/04/21/chat-gpt-market-predicting-stock-price-movements/).
- **Look-ahead/memorization:** Gao, Jiang & Yan "Detecting Lookahead Bias in LLM Forecasts" (arXiv 2512.23847) find memorization inflates apparent return predictability in a Bloomberg-headlines/Llama-3.3 test (memorization-amplified portion reported ~37% of baseline effect in one version; figures differ across versions) — [arXiv](https://arxiv.org/pdf/2512.23847). "The Memorization Problem" argues LLMs memorized large amounts of economic/financial data, challenging interpretations of forecasting ability — [arXiv 2504.14765](https://arxiv.org/html/2504.14765v2). Look-Ahead-Bench benchmark for point-in-time finance LLMs — [arXiv 2601.13770](https://arxiv.org/pdf/2601.13770). ESSEC "AI's Predictable Memory in Financial Analysis" — [ESSEC](https://faculty.essec.edu/research/16148-ais-predictable-memory-in-financial-analysis).
- **Alpha Arena Season 1 (nof1, crypto perps on Hyperliquid, $10k each, ended ~3–4 Nov 2025):** Qwen 3 Max won (~+22%); DeepSeek the only other profitable model; four US models lost money; GPT-5 lost ~62–63% — [Benzinga](https://benzinga.com/crypto/cryptocurrency/25/11/48651974/chatgpt-lost-63-trying-to-trade-crypto-but-one-china-ai-made-a-healthy-profit); [Forklog](https://forklog.com/en/four-out-of-six-ai-models-suffer-losses-in-trading-tournament/); mid-contest snapshots differed (Gemini imploding, DeepSeek/Grok up) — [Decrypt](https://decrypt.co/345006/ai-crypto-trading-showdown-deepseek-grok-winning-gemini-implodes). PnL was dominated by trading costs from overtrading — [Protos](https://protos.com/llm-crypto-trading-contest-finds-llms-cant-trade-crypto).
- **Alpha Arena Season 1.5 (US stocks, late 2025):** "Mystery model" revealed as Grok 4.20, +12.11% aggregate in two weeks while 7 others (incl. GPT-5.1, Gemini 3) lost; only 6 of 32 entries positive (range +34.59% to −96.15%); Claude Sonnet 4.5 entered, result not found — [Forklog](https://forklog.com/en/news/ai-model-grok-4-2-triumphs-in-trading-tournament); [aihola](https://aihola.com/article/grok-wins-alpha-arena-trading); [abit.ee](https://abit.ee/et/tehisintellekt/ai-mudelid-ebaonnestusid-taas-borsil-alpha-arena-season-1-5-tulemused). Nof1's founder said it's not yet feasible to hand an LLM money to trade on its own — [KuCoin News](https://www.kucoin.com/news/flash/ai-trading-models-struggle-in-live-market-tests-majority-of-systems-report-losses). Season 2 results not found.
- **Finder AU "Who Let the Bots Out? 2026 AI Portfolio Showdown"** (ChatGPT, Gemini, Copilot, DeepSeek, Perplexity, Meta AI, Grok; four 10-stock risk-profiled portfolios each; monthly rebalancing; Jan–Dec 2026; latest update 5 Nov 2026): October 2026 — every aggressive AI portfolio lost money (−0.5% to −16.1%) and trailed the Russell 2000 (+7.56%); most neutral portfolios beat the S&P 500 (−1.06%); DeepSeek conservative +15.11% (an unusually large monthly figure for a "conservative" portfolio) — [Finder AU](https://www.finder.com.au/insights/who-let-the-bots-out-2026-ai-portfolio-performance-showdown). Earlier, ChatGPT was the only portfolio positive in September (+4.32%) per search snippet — same source.
- **Rallies AI Stock Market Arena:** ChatGPT paper portfolio reported +72.4% since late Nov 2025 vs +11.3% S&P 500 (June 2026 report; paper trading) — [Crypto Briefing](https://cryptobriefing.com/chatgpt-leads-rallies-ai-stock-market-arena/). Finder UK tracker compares ChatGPT picks vs popular funds — [Finder UK](https://www.finder.com/uk/ai-investing). Benzinga: ChatGPT picks "outperforming 70% of funds" — [Benzinga](https://benzinga.com/z/32952065).
- **Concentration risk:** ChatGPT 5.0 household-portfolio study found ~20 assets with 18–20% in Nvidia — [Altiorem](https://altiorem.org/?p=25299).
- **Hallucination on filings:** FinanceBench (Patronus, 2023): GPT-4 Turbo with retrieval failed 81% of questions; long-context GPT-4 Turbo failed 21%, Claude 2 24%; closed-book GPT-4 Turbo 11% accuracy; oracle context 85% — [PR Newswire](https://prnewswire.com/news-releases/patronus-ai-launches-industry-first-llm-benchmark-for-finance-to-address-hallucinations-301990858.html); [arXiv 2311.11944](https://web3.arxiv.org/abs/2311.11944). FinBench-QA-Hallucination (Mar 2026) shows hallucination detectors degrade sharply (MCC −44% to −84%) with noisy retrieval — [arXiv 2603.20252](https://arxiv.org/html/2603.20252).
- **Claude-Alpaca bots:** no controlled backtests or long-run results; all self-reported paper snapshots — see Section 1 sources ([lablab.ai](https://lablab.ai/ai-hackathons/alpaca-ai-trading-agents-hackathon/guacalita/barco-alpaca-ai-trading-agent); [mejba.me](https://www.mejba.me/blog/claude-ai-automate-stock-trading)).

### Inferences
- Hype vs evidence: "ChatGPT beat the market by 70%" headlines come from months-long paper portfolios heavily tilted to AI/mega-cap winners (e.g., Nvidia concentration) during a strong tech run — a style/beta bet, not demonstrated skill.
- Most robust negative findings: overtrading/fees (Alpha Arena), concentration, hallucinated numbers without retrieval, look-ahead contamination in backtests. TradingAgents-style paper backtests on short windows are susceptible to the memorization problem.
- The defensible use case is analyst productivity (reading/summarizing/red-teaming primary documents with retrieval), not autonomous alpha.
- FinanceBench numbers are from 2023-era models; 2026 frontier models with long context are likely better, but no sourced current figure.

### Gaps
- No peer-reviewed independent replication of Lopez-Lira & Tang found in this pass.
- Claude's specific Alpha Arena results not found; Season 2 outcome not found.
- No current (2026) FinanceBench-style leaderboard for Claude Opus/Sonnet 4.x found.
- Finder AU cumulative YTD returns not published on the page (monthly only).

## 5. Best practices (prompt templates, pipelines, multi-agent debate)

### Takeaway
Consensus best practice: ground the model in primary documents or a data MCP (never rely on model memory for numbers), use role-based adversarial prompts (bull/bear, pre-mortem, forensic accountant, short-seller), screen quantitatively first and use AI for the deep dive, and require citations/quotes for every figure.

### Cited Findings
- Forensic red-flag prompt checklist: revenue recognition, segment reporting, leases, related-party transactions, contingencies, stock-based comp, goodwill ("You are a forensic equity analyst") — [Asian Century Stocks](https://www.asiancenturystocks.com/p/how-to-use-claude-for-equity-resear).
- Earnings-call/concall analysis: summarize, identify management focus, track sentiment over successive calls (Fritzell uses eight Coupang transcripts) — [Asian Century Stocks](https://www.asiancenturystocks.com/p/how-to-use-claude-for-equity-resear); Tijori produces concall transcript + AI summary on margins, guidance, capex — [TradingQnA](https://tradingqna.com/t/tijori-s-ai-stack-for-company-research/194604); Anthropic's earnings-reviewer agent chains call + filings → model update → note — [GitHub](https://github.com/anthropics/financial-services-plugins).
- Screener + AI deep-dive pipeline: Anthropic equity-research /screen (idea-generation) and market-researcher agent produce shortlists; Fritzell's scheduled Cowork watchlist scan flags >10% movers for review; Indian users paste/connect Screener.in or Trendlyne data — [GitHub](https://github.com/anthropics/financial-services-plugins); [Asian Century Stocks](https://www.asiancenturystocks.com/p/how-to-use-claude-for-equity-resear); [Trendlyne MCP](https://trendlyne.com/subscription/mcp/plans/).
- Multi-agent bull/bear debate: TradingAgents' bull and bear researchers debate analyst reports before trader/risk manager decide — [arXiv 2412.20138](https://arxiv.org/html/2412.20138v4); single-chat equivalent: steelman-the-bear prompt — [Assistly](https://getassistly.co/blog/how-to-use-claude-for-stock-analysis).
- Specify tickers, metrics and time periods; keep data requests manageable — [Claude Academy](https://academy.claude.com/tutorials/prompting-strategies-for-financial-analysis).
- Connect a data source rather than trusting chatbot recall for Indian company numbers — [LumiChats](https://lumichats.com/blog/ai-for-stock-market-investing-india-2026).
- For agents: paper-trade by default, daily-loss circuit breakers — [Alzarak/trading-bot](https://github.com/Alzarak/trading-bot); test LLM forecasts for look-ahead bias with point-in-time models/benchmarks — [Look-Ahead-Bench](https://arxiv.org/pdf/2601.13770).

### Inferences
- A sensible playbook pipeline: (1) quantitative screen (Screener.in/Trendlyne/Finviz-type) → (2) pull filings/transcripts via MCP or upload → (3) run saved prompt suite (overview, segments, moat, management, forensic, bull/bear/pre-mortem, short-seller) → (4) manually verify every number against source → (5) thesis tracker + catalyst calendar → (6) position sizing rules set by human, not model.
- Retrieval with long context, not RAG snippets alone, appears important given FinanceBench's 81% retrieval failure vs ~21–24% long-context failure (2023 models).

### Gaps
- No controlled study found comparing returns of investors who use AI-assisted research vs those who don't.
- Specific 10-K prompt templates from Chartloom not fetched.
