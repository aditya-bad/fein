# Roadmap: how every piece of work becomes a stock-selection machine

Last updated: 2026-11-21. **Rule:** every new task must name the stage below it builds, and what it unlocks
next. If a task fits no stage, don't do it.

## The machine we are building (the end state, phase B)
```
 1 UNIVERSE      every NSE/BSE + US small/mid company, point-in-time fundamentals, prices
       ↓
 2 HARD FILTERS  fraud/governance disqualifiers → removes the traps before we spend time
       ↓
 3 SIGNALS       ranked, *tested* reasons to look: earnings-surprise drift, promise credibility,
                 change detectors (pledge/insider/auditor), text changes, sector cycle turns
       ↓
 4 DEEP DIVE     "security-guard depth" protocol + flag-override judgment + variant view
       ↓
 5 VALUATION     reverse DCF, twin-engine room, valuation temperature, base rates
       ↓
 6 DECISION      probability-weighted thesis, kill criteria, position size, pre-mortem
       ↓
 7 SCOREKEEPING  every call dated with probabilities → Brier vs base rates → calibration
       ↺ feeds back into 2–6 (what worked, what didn't)
```
**Gate to phase B (bring ideas to the user):** stage 7 shows ≥50 resolved forward calls clearly beating
base rates, and at least one stage-3 signal proven out-of-sample after costs.

## Priority order for work (until phase B)
1. **Stage 7 + 3 together:** more forward calls each results season, *generated by the stage-3 signals*
   (e.g., PEAD quintiles, credibility scores), so we score the methods, not only the opinions.
2. **Stage 1** as soon as the Pi/Kite/Screener arrive (it unlocks everything else at full scale).
3. **Stage 2 back-test:** prove the filters remove traps without killing winners (use the 100 case studies + universe).
4. **Stage 4–6** templates, so every future deep dive outputs the same comparable fields.
5. Knowledge learning continues in the background, but only where it feeds a stage.
